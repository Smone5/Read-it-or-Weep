# Sound effects

These short effects were carried over from an earlier trivia project by the same author.
Where a source is known it is listed; if you reuse this repository, check the terms of each
source yourself, or replace the files (any short MP3 with the same name works).

| File | What it is | Source |
| --- | --- | --- |
| `correct.mp3` | right answer | Mixkit – "Correct answer tone" (2870), Mixkit Sound Effects Free License |
| `wrong.mp3` | wrong answer | Mixkit – "Wrong answer fail notification" (946), Mixkit Sound Effects Free License |
| `rimshot.mp3` | live reveal | Freesound – "rim shot" by jmayoff (256959) |
| `click.mp3` | button press | Freesound – "btn402" by junggle (26777) |
| `cheer.mp3`, `gameover.mp3`, `hint.mp3`, `levelup.mp3`, `tick.mp3`, `fasttick.mp3` | game sounds | from the earlier project; original source not recorded |
